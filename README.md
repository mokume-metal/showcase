# showcase

リリース済みの [mokume](https://github.com/mokume-metal/mokume) で動く、小さく真似しやすい作例集。
SNS で発信し、作例から API ごとにドキュメント ([mokume.org](https://mokume.org)) へつなぐ。

## 走らせ方

```bash
brew install mokume-metal/tap/mokume
mokume run <作例>
```
